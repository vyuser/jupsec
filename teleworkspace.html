02.6 · EPHEMERAL WORKSPACE

CREATE. USE. DETACH. RECOVER.

Create a workspace for a defined user, session or workload and discard it after the required activity.

USER→ AUTHENTICATE→ POLICY→ CREATE WORKSPACE→ WORK→ SESSION ENDS→ DESTROY / RECOVER
Reduce Persistence

The workload does not have to permanently reside on the endpoint.

Limit Access

Provide only the environment required for the task.

Support Contractors

Create controlled environments without permanently extending enterprise access.

Support Temporary Operations

Create workspaces for Training • Examination • Incident Response • Security Operations • Temporary Projects.
